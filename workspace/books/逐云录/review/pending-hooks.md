## Chapter 10 起笔 checklist — **破妄瞳首次觉醒章**（Bible 硬约束节点）

- [ ] **首觉触发条件**：必须是**濒死 + 极端情绪**复合触发，不能平白启眸。可选：
  - 陆家管事或护卫队正面拦截，沈逐云重伤将死；
  - 云毒侵至心脉，寿元骤减；
  - 老妇孙儿消息实体化（陆家挟持 / 尸首被弃裂口边），情绪爆发。
  - 推荐融合：老妇孙儿被陆家搜山队所害 → 主角暴怒 + 身受重伤 → 破妄瞳濒死启眸。
- [ ] **觉醒具象化**：不要用"破妄瞳，觉醒"直白词。用体感描写——左眼如裂镜重铸、万物云痕显形、陆家护卫云核命门如细线浮现、敌方云气裂纹一览无遗。折寿一刻立即兑现，眼底见血。
- [ ] **战力上限守死**：Bible 规定每日三次、每次不超十息，超用则瞳裂流血失明三日。首觉只用一次、维持数息即散，**不能变成战力爆表主宰全场**。打倒小队靠"看破命门 + 借玉片血祭屏障 + 孤注一掷"组合，代价重到几乎走不出来。
- [ ] **回收老妇支线**：孙儿下落揭晓 / 烫伤原因揭晓 / 老妇命运落点（死亡或护主角走而自己断后）。Auditor flag 老妇被工具人化，ch10 必须给落点。
- [ ] **血脉验门部分解释**：首觉后玉片反应异常（裂痕扩大 / 青气外溢），暗示嫡系身份被夺虽断名分却未完全截断血脉共鸣（留更深的设定给 ch11-12 揭）。
- [ ] **H001 推进**：首觉中借破妄瞳看到地库入口的"云痕钥孔"真正位置（与 ch8 暗记互补）。
- [ ] **结尾克制**：觉醒 + 脱险 + 伤重昏迷。不要直白情绪总结。
